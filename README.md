# Prominence II ES — Tomodachi

Modpack **Prominence II: Hasturian Era 4.0.1hf** con la traducción propia al
español y los ajustes del grupo.

Esto es un pack de [packwiz](https://packwiz.infra.link/): **no contiene los mods**,
solo las referencias para que cada uno los baje de su fuente original
(CurseForge / Modrinth). Las tres excepciones están explicadas abajo.

## Qué trae

| | |
|---|---|
| Minecraft | 1.20.1 |
| Fabric Loader | 0.19.3 |
| Mods | 442 |
| Traducción | mods, misiones (FTB Quests), menús e imágenes con texto |

## Cómo se instala

Pedile a Agustín el zip de la instancia y en Prism Launcher:
**Add Instance → Import from zip**.

Desde ahí se actualiza solo: cada vez que abrís el juego, el pack se sincroniza
con este repo. Si se agrega un mod o se corrige la traducción, te llega sin hacer
nada.

## Los 3 jars que sí están acá

`Prominent`, `common-networking` y `EMIProfessions` no existen como proyectos
publicados en CurseForge ni Modrinth: vienen dentro del modpack. Como no hay de
dónde referenciarlos, van incluidos. El resto de los mods NO se redistribuye.

## Dos cosas importantes

- **No saques el inglés del menú de idiomas.** Es un bug conocido del modpack: si
  lo quitás, el juego se queda sin texto. Poné el español arriba, pero no lo borres.
- **No uses el botón "Traducir" del FTB Quests Translator.** Las misiones ya están
  traducidas a mano; ese botón las pisaría con una traducción automática.
