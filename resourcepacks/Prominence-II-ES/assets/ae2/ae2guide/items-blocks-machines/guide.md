# La Guía

<ItemImage id="guide" scale="8" />

### Esta guía que estás leyendo ahora, para todas tus necesidades de guía de AE2.

* Accede a la barra lateral de la izquierda para encontrar una tabla de contenidos
* Muchas páginas tienen escenas interactivas. Si una escena tiene botones de zoom ![Más](../assets/diagrams/plus.png)
  y ![Menos](../assets/diagrams/minus.png) junto a ella, puedes rotar y mover la cámara.
  Haz clic izquierdo y arrastra para rotar, haz clic derecho y arrastra para desplazar.
