# La Tarjeta de Memoria

<ItemImage id="memory_card" scale="4" />

La Tarjeta de Memoria se usa para copiar y pegar configuraciones entre [dispositivos](../ae2-mechanics/devices.md) de AE2, y para vincular [túneles P2P](p2p_tunnels.md). También puede pegar [tarjetas de mejora](upgrade_cards.md) en los dispositivos.

- Mayús izdo. + clic derecho para copiar la configuración o generar una nueva frecuencia de enlace P2P.
- Clic derecho para pegar la configuración, las tarjetas de mejora o la frecuencia de enlace.
