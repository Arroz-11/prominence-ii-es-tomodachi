# La Fibra de Cuarzo

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/assemblies/quartz_fiber.snbt" />
<IsometricCamera yaw="195" pitch="30" />
</GameScene>

La fibra de cuarzo se usa para compartir energía entre [redes](../ae2-mechanics/me-network-connections.md), manteniéndolas separadas. Esto te permite alimentar
[subredes](../ae2-mechanics/subnetworks.md)
sin necesidad de poner aceptadores de energía y cables de energía por todas partes. También se puede usar para evitar que los cables se conecten,
aunque usar cables de colores diferentes, o usar <ItemLink id="cable_anchor" /> es más barato y efectivo.

Son [subpartes de cable](../ae2-mechanics/cable-subparts.md).
