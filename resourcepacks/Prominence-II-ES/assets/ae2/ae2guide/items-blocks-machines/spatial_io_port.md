# El Puerto IO Espacial

<BlockImage id="spatial_io_port" p:powered="true" scale="8" />

El Puerto IO Espacial se usa en [IO espacial](../ae2-mechanics/spatial-io.md) para sostener la [celda espacial](spatial_cells.md)
y controlar la operación de IO espacial.

La celda se puede insertar y extraer con cualquier logística de objetos como tolvas o buses de AE2, si quieres automatizarlo.
