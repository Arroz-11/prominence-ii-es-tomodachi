# El Pílon Espacial

<BlockImage id="spatial_pylon" p:powered_on="true" scale="8" />

El Pílon Espacial se usa en [IO espacial](../ae2-mechanics/spatial-io.md) para generar el campo espacial y definir el volumen
a afectar.

Cada línea continua de pilones usa 1 [canal](../ae2-mechanics/channels.md)

Las líneas de pilones deben tener al menos 2 bloques de largo para funcionar.
