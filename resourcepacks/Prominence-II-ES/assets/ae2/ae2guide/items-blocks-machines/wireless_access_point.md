# El Punto de Acceso Inalámbrico

<BlockImage id="wireless_access_point" p:state="has_channel" scale="8" />

Permite el acceso inalámbrico a través de un <ItemLink id="wireless_terminal" />.
El alcance y el uso de energía se determinan según la cantidad de <ItemLink id="wireless_booster" /> instalados.

Una red puede tener cualquier número de puntos de acceso inalámbricos con cualquier número de <ItemLink id="wireless_booster" /> en cada uno, lo que te permite optimizar el uso de energía y el alcance alterando tu configuración.

Requiere un [canal](../ae2-mechanics/channels.md).

También se usa para vincular [terminales inalámbricos](wireless_terminals.md)

# Potenciador Inalámbrico

<ItemImage id="wireless_booster" scale="2" />

Se usa para aumentar el alcance del punto de acceso inalámbrico.
