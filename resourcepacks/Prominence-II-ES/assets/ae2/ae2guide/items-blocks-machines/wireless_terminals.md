# Terminales Inalámbricas

<Row>
  <ItemImage id="wireless_terminal" scale="4" />

  <ItemImage id="wireless_crafting_terminal" scale="4" />
</Row>

Las terminales inalámbricas son versiones portátiles de las [terminales](terminals.md) cableadas normales. Tienen exactamente las mismas interfaces que sus contrapartes cableadas, excepto que en lugar de ranuras para <ItemLink id="view_cell" />, tienen ranuras para [mejoras](upgrade_cards.md).

Para vincularlas con una red, inserta la terminal en la ranura superior derecha de un <ItemLink id="wireless_access_point" /> conectado a esa red. (La ranura con una imagen de una terminal inalámbrica y una flecha debajo).

Deben estar dentro del alcance de un <ItemLink id="wireless_access_point" /> para funcionar.

Su energía se puede recargar en un <ItemLink id="charger" />.

# Terminal de Crafteo Inalámbrica

<ItemImage id="wireless_crafting_terminal" scale="4" />

La Terminal de Crafteo Inalámbrica es similar a una terminal inalámbrica normal, con todos los mismos ajustes y secciones, pero con una cuadrícula de crafteo adicional que se rellenará automáticamente desde el [almacenamiento de la red](../ae2-mechanics/import-export-storage.md). ¡Ten cuidado al hacer clic con shift en el resultado!

## La interfaz

Ver [terminales](terminals.md)

## Mejoras

La Terminal de Crafteo Inalámbrica admite las siguientes [mejoras](upgrade_cards.md):

*   <ItemLink id="energy_card" /> para aumentar la capacidad de la batería
