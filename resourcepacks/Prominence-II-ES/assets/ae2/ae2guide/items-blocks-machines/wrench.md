# Llaves Inglesas

<Row>
  <ItemImage id="certus_quartz_wrench" scale="4" />

  <ItemImage id="nether_quartz_wrench" scale="4" />
</Row>

Las llaves inglesas se usan para rotar dispositivos de ae2 (clic derecho) y desmontar bloques de ae2 (clic derecho con shift).
Los [subcomponentes](../ae2-mechanics/cable-subparts.md) se pueden quitar de un cable sin romper todo lo que hay en el cable
(o el cable se puede quitar sin romper los subcomponentes).

Muchos bloques de ae2 se pueden rotar, así que solo porque esta guía no diga que puedes rotar algo no significa que no puedas.
